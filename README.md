## 💻 Projects

**[UIU BookHUB](https://github.com/Mahamudul496/UIU-BookHUB)** · *Team Project*  
A web platform where UIU students buy, sell, donate, and discover
academic books. Features include authentication, search and filters,
wishlist, purchase requests, student chat, seller ratings, and admin
approval. Built with PHP, MySQL, HTML, CSS, and JavaScript.



**[Go-Green](https://github.com/Mahamudul496/Go-Green)** · *Team Project*  
A reward-based waste management system. Users submit recyclable waste,
schedule pickups, and earn eco-points based on waste type and weight.
Features include admin verification and rewards. Built with PHP,
MySQL, HTML, CSS, and JavaScript.

**[Road Ambulance](https://github.com/Mahamudul496/Road-Ambulance-Project)** · *Team Project*  
A desktop application for finding emergency ambulance and hospital
support. Includes user profiles, ambulance and hospital details,
map view, SOS functionality, and client-server chat. Built with
Java, JavaFX, and Maven.

**Vehicular Cloud Networks** · *Research Project*  
Exploring proactive task migration to maintain service continuity
as vehicles move between roadside and edge computing areas.
Working with SUMO, Python, and NS-3.
